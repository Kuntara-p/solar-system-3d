# 🪐 ระบบสุริยะจำลอง (Interactive Solar System Explorer 2D / 3D)

สื่อการสอนดาราศาสตร์เชิงโต้ตอบแบบ **Offline-First Static Web App** รองรับทั้งโหมด **3 มิติ (WebGL / Three.js)** และ **2 มิติ (HTML5 Canvas)** สามารถเปิดใช้งานได้ทันทีโดยดับเบิลคลิก [index.html](index.html) หรืออัปโหลดขึ้น GitHub และ Vercel ได้โดยไม่ต้องตั้งค่า Build เพิ่มเติม

## ✨ ความสามารถหลัก
- **สลับโหมด 3D / 2D ได้ทันที:**
  - **โหมด 3D:** หมุนมุมกล้องรอบระบบสุริยะ 360°, ปรับมุมมองสำเร็จรูป (มุมเอียง 3 มิติ / ด้านบน / ด้านข้าง), แสดงแกนหมุนและมุมเอียงจริงของดาวเคราะห์ (เช่น โลก 23.4°, ดาวยูเรนัส 97.8° นอนกลิ้ง), แสดงระนาบวงโคจรเอียงของดาวพลูโตและดาวหาง, แถบดาวเคราะห์น้อย 3 มิติ และหางดาวหางชี้ออกจากดวงอาทิตย์
  - **โหมด 2D:** ผังระบบสุริยะแบบ 2 มิติคมชัดพร้อมดวงจันทร์โคจรรอบโลกและแสงเงา
- **ตัวกรองกลุ่มดาว:** `ทั้งหมด` | `ดาวเคราะห์ชั้นใน` | `ดาวเคราะห์ชั้นนอก` | `ดาวเคราะห์แคระ & ดาวหาง`
- **การ์ดข้อมูล + เครื่องคำนวณน้ำหนักและอายุบนดาวอื่น**
- **ห้องทดลองเทียบขนาด (Compare Lab):** เทียบขนาดดาวเคราะห์ด้วยกัน และเทียบกับดวงอาทิตย์ (109× ของโลก)
- **ภารกิจ Quiz 10 ข้อ** พร้อมคำอธิบายเฉลยทุกข้อ

## 📂 โครงสร้างไฟล์
- `index.html` — หน้าเว็บหลัก
- `styles.css` — สไตล์ธีมอวกาศและ Responsive UI
- `vendor/three-bundle.min.js` — Three.js + OrbitControls แบบ Offline IIFE Bundle
- `src/solarData.js` — ข้อมูลดาราศาสตร์ คำถาม Quiz และคณิตศาสตร์วงโคจร 2D/3D
- `src/renderer.js` — ตัววาดโหมด 2D และผังเทียบขนาด
- `src/planetTextures3d.js` — ตัวสร้างแผนที่พื้นผิว 3D Spherical FBM และ Custom GLSL Shaders
- `src/renderer3d.js` — ตัววาดโหมด 3D (WebGL + `InstancedMesh` Asteroid Belt + Raycasting)
- `src/app.js` — ตัวควบคุมการทำงานหลัก
- `tests/solarData.test.mjs` — ชุดทดสอบคณิตศาสตร์วงโคจรและข้อมูล (`node --test tests/solarData.test.mjs`)

## 🚀 การอัปโหลดขึ้น GitHub และ Deploy บน Vercel
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น GitHub Repository (ไม่จำเป็นต้องมี `node_modules`)
2. เข้า [Vercel](https://vercel.com) → **Add New Project** → เลือก Repository ของคุณ
3. ตั้งค่า Framework Preset เป็น **Other** (หรือปล่อยค่าเริ่มต้นโดยไม่ต้องใส่ Build Command) แล้วกด **Deploy** ได้ทันที
